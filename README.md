# COURSEFLOW – College Course Registration & Waitlist Management

## Project Explanation

COURSEFLOW is a web-based application designed to simplify college course registration and waitlist management. It allows students to register for courses, check seat availability, search for student records, update student details, and withdraw from courses.

When a course reaches its maximum capacity, additional students are placed on a waitlist. The application follows the **First-In, First-Out (FIFO)** principle to ensure that the student who joined the waitlist first gets the next available seat when a registered student withdraws.

The project demonstrates the practical use of **Linked Lists and Queues concepts** in managing student registrations and course availability. It is developed using HTML, CSS, and JavaScript, with browser Local Storage used to retain application data.

## Project Implementation

1. **View Courses:** Browse the available courses and check their seat availability.
2. **Register for a Course:** Enter the student's details and select a course.
3. **Join the Waitlist:** If a course is full, the student is added to its waitlist automatically.
4. **Manage Registrations:** Search for students, update their names, or withdraw them from courses.
5. **Automatic Seat Allocation:** When an enrolled student withdraws, the first student in the waitlist is promoted automatically.
6. **Add Courses:** Add new courses and define their seat capacities.
7. **View Records:** Check enrolled students and waitlisted students for each course.

## Technologies Used

- HTML – Structures the user interface
- CSS – Styling and layout
- JavaScript – Application functionality and registration logic
- Browser Local Storage – Local data persistence

## Expected Outcome

COURSEFLOW provides a simple and interactive way to manage course registrations, monitor seat availability, and handle waitlists fairly. It demonstrates how fundamental data structure concepts can be applied to a real-world college administration problem.
